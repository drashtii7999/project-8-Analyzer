# 📊 NumPy Analyzer

## 📌 Project Description
NumPy Analyzer is a Python-based data analytics project developed using NumPy and Object-Oriented Programming (OOP). It allows users to create and manipulate arrays, perform mathematical operations, analyze statistical data, and calculate correlation through a menu-driven program.

## ✨ Features
1. **Create Array:** Creates 1D, 2D, and 3D arrays.
2. **Display Array:** Displays the array, dimensions, shape, and size.
3. **Indexing and Slicing:** Accesses array elements and extracts selected portions.
4. **Combine Arrays:** Combines two arrays into one.
5. **Split Array:** Divides an array into equal parts.
6. **Mathematical Operations:** Performs addition, subtraction, multiplication, division, and matrix multiplication.
7. **Search, Sort and Filter:** Searches for values, sorts elements in ascending or descending order, and filters values.
8. **Statistical Analysis:** Calculates sum, mean, median, standard deviation, variance, minimum, maximum, and percentiles.
9. **Correlation:** Calculates the correlation coefficient between two arrays.
10. **Project Information:** Displays the project name and technologies used.

## 🧰 Technologies Used
- Python 3
- NumPy
- Object-Oriented Programming (OOP)
- Classes and Objects
- Functions and Methods
- Exception Handling

## ⚙️ Installation

1. Install Python 3 on your computer.
2. Install the NumPy library using the following command:

```bash
pip install numpy
```

## ▶️ How to Run the Project

1. Open the project folder in Visual Studio Code.
2. Open the terminal.
3. Run the following command:

```bash
python main.py
```

4. Select an option from the displayed menu.
5. Enter the required values to perform the selected operation.
6. Select `0` to exit the program.
